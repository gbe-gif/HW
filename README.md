# Bencroft After Dark

벤크로프트 RP 세계관을 위한 반응형 멀티 페이지 소개 사이트.
짙은 그린, 헤리티지 골드, 고딕 건축에서 가져온 시각 요소와 간단한 캠퍼스·주거지 약도로 구성했습니다.

## 페이지

- `/`: 캠퍼스 7곳과 주거지 4곳을 연결하는 약도. 캠퍼스/주거지 필터, 지도/목록 보기, 확대·축소 제공.
- `/campus/`: 대학의 배경, 상징, 주요 장소와 할로윈의 풍경.
- `/after-dark/`: 축제 일정, 초록·황금 도토리 규칙, 행사 장소 연결.
- `/residences/`: 데클란·제이스·토비·콜튼의 집 위치와 층별 구성.
- `/characters/`: 주연 4인의 소개, 기본 정보 배지, 할로윈 코스튬, 주거지 연결. 비밀 내기는 목표·보상·규칙만 접힌 상태로 제공.
- `/supporting/`: 조연 소개 준비 공간. 미제공 설정은 임의 생성하지 않음.
- `/gallery/`: 내비게이션 마지막의 수록 이미지. D/J/T/C 각 1~11번, 총 44개. 인물별 필터와 원본 보기 제공.

약도는 정확한 주소나 실측 지도가 아닙니다. 제공된 위치 관계를 바탕으로 배치한 개념도이며, 확인된 이동 시간은 주거지 상세에 따로 표기합니다. 건물 일러스트는 분위기를 전달하는 콘셉트 이미지입니다.

## Vercel 배포

1. Vercel에서 **Add New → Project** 선택.
2. GitHub 저장소 `gbe-gif/HW`를 Import.
3. Root Directory는 저장소 루트. Framework Preset은 **Other**.
4. Build Command는 `npm run build`, Output Directory는 `dist`.
5. Deploy 실행.

`vercel.json`에 빌드 및 출력 경로가 설정되어 있습니다. 환경 변수와 외부 서비스 키가 필요하지 않습니다.
설정 근거: https://vercel.com/docs/builds/configure-a-build

## 로컬 실행

Node.js 20 이상. 외부 npm 의존성 없음.

```sh
npm run build
npm run check
npm run dev
```

브라우저에서 `http://127.0.0.1:4173` 열기.
소스 수정 후 `npm run build`를 다시 실행하고 브라우저를 새로고침합니다.

## 파일 구성

- `data.mjs`: 가공한 장소·주거지 설정. 신규 정보 수정 지점.
- `characters.mjs`: 공개용으로 가공한 주연 설정과 내기 규칙. 참가 이유·동기는 포함하지 않음.
- `gallery.mjs`: 수록 이미지 주소 규칙과 갤러리 페이지.
- `character-pages.mjs`: 주연·조연 페이지와 축제 코스튬 링크 생성.
- `art.mjs`: SVG 아이콘, 약도와 콘셉트 건물 일러스트.
- `build.mjs`: 공통 레이아웃과 페이지를 정적 HTML로 생성.
- `public/styles.css`: 반응형 레이아웃, 색상, 하단 내비게이션.
- `public/app.js`: 약도 필터, 목록 보기, 확대·축소, 장소 미리보기.
- `check.mjs`: 내부 링크·앵커, 장소 수, 상세 정보 누락 검사.
- `server.mjs`: 로컬 미리보기 서버.
- `dist/`: 빌드 결과. 버전 관리에서 제외하며 Vercel에서 생성.

## 콘텐츠 및 접근성 원칙

- 설명은 말머리표와 명사형 종결을 사용하고, 원본 프롬프트는 공개하지 않음.
- 아직 제공되지 않은 인물 설정, MBTI 외 성격유형·원문 키워드, 말투 예시는 노출하지 않음.
- `Ⓤ`는 `당신`으로 표기. 제공된 나이·성별·별명·생일·키·MBTI만 배지로 표시.
- SVG는 고유 viewBox 비율, 이미지에는 `height: auto`를 적용.
- 지도 마커는 실제 링크. 자바스크립트가 꺼져 있어도 상세 페이지 이동 가능.
- 모바일 약도는 가로 스크롤, 목록 보기로 모든 장소 접근 가능.
- 키보드 초점, 본문 바로가기, 현재 페이지 표시, 동작 줄이기 설정 지원.
- 외부 폰트, 지도 API, 분석 도구 없음. 수록 이미지는 사용자가 지정한 `https://gbe88.uk/HW/`에서 직접 불러옴.

## 위치 및 스포일러 정책

- 파인 릿지의 데클란·콜튼 주택은 같은 단지의 안쪽과 입구 쪽에 모아 배치. 두 집 사이 도보 10분 이내, 캠퍼스 동서 도보 35분 표기. 정문은 남서쪽.
- 토비의 체스트넛 홀은 공대 쪽 서편 주거지, 제이스의 C.QE는 동문 너머 번화가. 미제공 이동 시간은 추가하지 않음.
- 비밀 내기는 기본 접힘 상태. 각 인물의 참가 계기·속내는 공개 데이터와 화면 모두에서 제외.

## 수록 이미지 업로드

`https://gbe88.uk/HW/{구분}_{숫자}.webp`에 파일을 업로드합니다. 구분은 D=데클란, J=제이스, T=토비, C=콜튼이며, 번호는 1~11입니다. 앞에 0을 붙이지 않습니다. 예: `D_1.webp`, `C_11.webp`.

이미지가 없거나 불러오지 못하면 준비 상태를 표시합니다. 업로드 후 페이지를 새로 열거나 새로고침하면 재시도합니다. 이미지가 보일 때 접근할 수 있는 원본 링크도 제공합니다.

이미지에는 높이·비율을 고정하지 않고 `width: 100%; height: auto; object-fit: contain`을 적용합니다. 원본 전체를 보여주며, 화면 근처에 도달한 이미지부터 요청합니다. 파일을 올릴 때 사이트를 다시 배포할 필요는 없습니다.
